# Viresh — Motion Portfolio

A cinematic, animation-heavy developer portfolio built with React, Vite, Three.js, GSAP, ScrollTrigger, and Lenis.

## Features

- Interactive procedural 3D hero rendered with Three.js
- GSAP and ScrollTrigger scroll choreography
- Smooth scrolling with Lenis
- Animated navigation, project gallery, cursor interactions, parallax, and ticker
- Responsive layout and reduced-motion support

## Getting started

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Customize

Update the content and project data in `src/App.jsx`, the Three.js scene in `src/components/ThreeHero.jsx`, and the styling in `src/styles.css`.

Replace placeholder project links and contact details before publishing.
